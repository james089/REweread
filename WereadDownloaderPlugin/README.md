# WereadDownloaderPlugin

微信读书 → EPUB → reMarkable 原生书库。插件已接入独立登录、左栏入口、书架缓存、封面、分页、多选和原生书库导入。

目标是在系统主界面左栏 AppLoad 下方提供独立入口，按封面列表选择书籍，完整下载后自动导入原生书库根目录；已存在的书禁止重复导入。

详见 [研究与执行计划](RESEARCH_AND_PLAN.md)。本目录与现有阅读客户端分离，不改变其 UI、账号或用户缓存。

## 当前实现

- `src/epub.*`：在 OPF 中追加 `urn:weread:book:<bookId>` 和插件标记，保留已有出版标识及资源；写入后重新读取确认。ZIP 不解压到文件系统，验证 CRC、路径、manifest/spine，并限制压缩文件和展开内容各最多 64 MiB。暂不支持 ZIP64、多 package、远程 manifest 资源或超过该上限的书，不能据此宣称支持所有 EPUB。
- `src/import_registry.*`：进程互斥、私有权限、原子保存、提交前事务落盘；未知结果保持 pending。完整系统书库快照可按来源 ID 恢复 UUID 关联，不根据书名匹配。缺失/不完整扫描不得改变已导入状态。
- `lua/parallel_download.lua`：最多三个并行章节下载通道，复用原有章节重试、断点和 EPUB 打包流程。设备单次 8 章样本中，双通道比串行快约 23%；三通道仍需在设备上实测，实际收益会随网络及书籍变化。
- 新书开始下载时复用下载器已读取的云端阅读位置快照；下载结束后将快照与经过清单校验的章节目录一起缓存。导入后优先从本地 XHTML 恢复到系统生成的 PDF，避免重复请求目录和章节正文；快照在本次自动导入时一次性消费，之后重试会重新读取云端。
- 长按书籍进入多选，顶部显示“导入（N）”，返回退出多选。单本导入可在下载期间继续入队，点击“排队中”取消该项；禁用的取消和单本导入按钮不占布局空间。
- `native/INTEGRATION.md`：固定版本的上游接口、左栏定位点与尚未通过的真机门槛。

运行独立合成行为测试：

```sh
bash WereadDownloaderPlugin/scripts/test-core.sh
```

默认使用本仓库现有宿主 Qt5 测试环境 `/opt/anaconda3`，可通过 `QT_PREFIX`、`QT_INCLUDE`、`QT_MAJOR`、`CXX` 修改。测试临时创建合成 EPUB 和状态库，结束清理，不连接设备或账号。

官方 chiappa SDK 核心构建：

```sh
bash WereadDownloaderPlugin/scripts/build-sdk.sh
```

该脚本构建核心库、下载 worker、原生扩展和隔离测试程序，不安装、不启动设备程序、不重编现有阅读器。安装前仍需精确固件的资源回放及加载检查。
