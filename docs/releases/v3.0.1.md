# REweread 3.0.1

Source-only 3.0.1 milestone. 非官方源码维护版本，不提供公开二进制、SDK、字体或第三方运行时。

## 修复内容

- 使用 chiappa SDK 5.8.203 / Qt 6.10.3 匹配设备，消除旧 QML 字节码失效带来的现场编译；启动脚本显式设置可写缓存目录。
- 构建前校验 SDK Qt 版本，不匹配时拒绝构建并保留旧产物。保留 Docker 构建，支持已安装 SDK 的 aarch64 Linux 主机直接构建。
- 同一下载客户端复用同一本书的阅读状态，最多 30 秒；无效页面不缓存，章节失败后立即刷新状态再有界重试。
- 后台下载完成不再强制切书；只响应明确的打开请求、目录选择或仍在当前书的续传。
- 识别 HTTP 200 中的登录业务错误，修复“登录超时”被误报为“没有可下载章节”和 Cookie 续期失败被误报为成功的问题。
- 包含此前已通过用户验收的自由笔迹翻页、橡皮和清空修复。

## 验证结果与范围

- 官方 SDK 构建、全套源码验证、仓库安全与 Shell 语法检查通过。
- SDK 拒绝、下载导航、设备 LuaJIT 缓存到期/隔离/异常/续传行为回归通过。
- 空缓存首次与重复启动的 Qt 首帧分别为 4957 / 4903 ms，无 QML 版本、依赖校验或缓存保存错误。计时从应用 main 开始，系统切换和墨水屏物理刷新另计。
- 同组 8 个真实章节：22.0 → 12.8 秒，网络读取量约减少 73%；正文、CSS 和图片逐字节一致。
- 隔离整本下载：106/106 章、失败 0、184 秒。真实 Main/ReaderStore 笔迹回归通过，退出后系统正常且 NRestarts=0。

上述结果对应本轮功能代码、版本字段更新前的设备构建；校验和见
[性能验收记录](../performance-investigation-2026-10-13.md)。本次 3.0.1 同步源码和文档，不重新部署设备。
样本耗时不代表所有书籍或网络条件；没有切换官方原生批量接口。本机手写仍不会自动上传，云端写入、完整字体矩阵、长期电池及干净设备安装/卸载等原有限制保留。
