# REweread 3.0.0

Source-only 3.0.0 milestone. 非官方源码更新，不提供公开二进制、SDK、字体或第三方运行时。

## 本版内容

- 本月、每日、分书阅读统计；仅统计本机实际前台阅读。
- 阅读时长持久账本和不确定上传状态保护；个人云笔记离线缓存与保守进度定位。
- 下载章节校验、续传、有限重试和 partial EPUB 状态。
- 字体预览选择器、图文混排分页改进。
- 系统 3.28.0.172 刷新 ABI 适配，AppLoad v0.6.0 与带崩溃保护的启动恢复方案。

## 验证与限制

此前已在 3.28.0.172 验证 AppLoad 入口、重启持久化、退出恢复系统，字体/图文/统计页及 direct-ink 小区域恢复探针通过。用户随后发现自由手写残留和橡皮无效，本轮单独修复；不能把此前探针通过当作自由手写验收。

本轮修复记录：快速墨迹逐像素保留首次改写前的背景，清除/离页时恢复；橡皮支持当前页自由笔画的几何命中删除，含页边空白和待保存笔迹。2026-10-12 的设备 `ink-lifecycle` 自检通过直写清除、持久画布清除和隐藏恢复，退出后 Xochitl active、NRestarts=0。该自检不打开真实账号/笔记；真实连续书写和用户原页复测仍需用户确认，不以自检替代。

最终构建 SHA-256：`fa4f551814b6d16b236ee49bf8c4c4bb081c00608bc2e89700f83723784ef303`。旧应用保留了时间戳备份；未重装 XOVI、未升级系统、未执行用户数据清理。补充设备测试也覆盖 `finishStroke()` 停笔后由 Qt 持久笔迹接管显示。

本地验证：完整 `tests/run-all.mjs`、shell 语法、仓库安全检查、官方 SDK 构建、Qt 账本/下载/笔记行为测试、原始像素还原测试及真实 ReaderStore 橡皮测试通过。橡皮覆盖单点、交叉扫线、远离共线、不相交、跨书跨页隔离、保留高亮、空输入和持久化重载；测试只使用临时数据目录。

真实账号时长/进度上传、整本离线下载、52 组字体行距矩阵、长期笔迹与电池测试仍未全部完成。原生章节偏移编码仍待确认；本地手写不会自动上传。干净设备安装/卸载及服务与上游权利问题仍阻止普通用户二进制分发。

## 2026-10-13 自由笔迹后续修复

旧版空白画布自检未覆盖真实阅读页，用户复测仍发现残留。后续确认 QML 的 `root.selfTestMode` 未声明，导致正常翻页跳过笔迹加载；同时存在完整笔画脏区域计算和直写背景过早释放问题。本轮已修复这些问题，并避免旧页延迟保存覆盖当前页的笔迹模型。

新增隔离的真实 Main/ReaderStore 中文正文测试，覆盖多笔保存、翻页返回、橡皮、清空及像素恢复、重新分页，设备连续两轮通过。随后用户实测确认上述问题“都解决了”。修复构建 SHA-256：`ef4df20c2e616a7126fa13c7e7f7c7481c1f570e178c0d35edc6706672f18b78`，取代上文历史构建。原有数据、API Key、字体和系统配置保留。

此验收针对普通阅读页的翻页、擦除与清空，不代表自由笔迹已实现跨字体/字号重排的稳定正文锚定。
