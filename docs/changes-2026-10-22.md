# 本次改动汇总（2026-10-22）

本文汇总当前工作区相对上一提交的主阅读器和原生下载插件改动。各阶段验收细节分别见 `agent-handoff.md`、`reader-performance-2026-10-21.md` 和 `../WereadDownloaderPlugin/DEVICE_HANDOFF.md`。

## 主阅读器

- 统一完整 EPUB 判定，已有可信完整文件不因后续任务状态变化失去可读性；未完成书进入完整下载流程，已完成书可直接离线阅读。
- 下载前解析真实书名，详情和封面显示当前书籍的章节进度；修复删除后书架状态、文字透明度和完成徽标未及时更新的问题。
- 阅读设置铺满可用宽度，字体与字重分行；统一标题、边距及底部按钮样式和手指/笔命中区域。书架导航、同步/退出图标和绿色圆底白勾同步调整。
- 正常阅读停用笔迹入口并保留旧数据；阅读进度在连续翻页后合并落盘，退出、休眠和切书强制保存。翻页交互期间暂停补排，减少重复正文更新。
- 页脚增加章节入口和全书页码，提供独立的页面预览/跳转；全书索引空闲分步计算，单独持久化并按内容和排版变化失效。
- 修复阅读同步对成功响应的判定，补充下载、恢复、进度保存、分页、跳转和同步的验证。

## WereadDownloaderPlugin

- 新建独立子项目，在系统左栏 AppLoad 下方提供入口，使用独立扫码登录和私有账号缓存。
- 按最近阅读时间显示分页书架，包含本地封面、导入状态、主阅读器同款绿底白勾；支持左右滑动翻页和当前页优先补齐封面。
- 默认先加载本地书架并核对系统导入状态，缓存过期后同步；修复首屏封面必须翻页才出现、下载进度导致整列徽标重建的问题。
- 复用既有章节下载、断点校验、重试和 EPUB 打包，最多两个章节通道并行。修复插图请求处于不可暂停回调时造成的协程错误；并发失败可从校验后的断点转串行。
- EPUB 写入来源书籍 ID，按来源标识防止重复导入。通过系统原生 HTTP 导入根目录，修复 multipart 头格式兼容问题；未知提交结果保留待核实状态。
- 系统书库移除后可利用完整本地 EPUB 再次导入。按最终需求取消插件内“移出书库”入口和实现。
- 登录按需续期，过期后先续期重试；网络异常保留登录。标题右侧显示账号名称，确认退出后清除插件凭据并返回扫码页，保留书籍及封面缓存。
- 弹窗使用全屏暗色遮罩、加大内边距及等宽按钮；所有操作按钮统一圆角和左右留白，账号/返回按钮等高。
- 长按书籍进入多选，返回退出；批量按钮为“导入（N）”。禁用的取消和单本操作折叠，多选时隐藏单本导入。
- 下载期间可继续添加其他书籍到串行队列，排队条目再次点击可取消；避免重复入队，并在取消、关闭或失败时恢复等待项状态。
- 提供精确固件门禁、原生资源补丁回放、清单校验、备份及超时回滚的安装流程。
