# 开源许可与外部权利边界

本文说明 REweread 项目自有代码的 MIT 授权，以及该授权没有覆盖的服务、内容、商标和第三方依赖。它不是法律意见；具体发行或产品化前应由合格律师结合实际用途审查。

## 结论

1. 本仓库当前项目自有代码采用 [MIT License](../LICENSE)。MIT 是 OSI 批准的开源许可证，允许使用、复制、修改、合并、发布、分发、再许可、销售副本及其他商业使用，但必须保留版权和许可声明。
2. MIT 只能许可仓库权利人拥有或有权再许可的代码。它不授予微信读书服务、书籍内容、评论、账号数据、商标、第三方插件、字体或设备运行时的权利。
3. 本项目与腾讯、微信读书或 reMarkable 没有隶属、授权、认可或合作关系。开源、免费或非商用都不代表相关服务使用已经获准。
4. 微信读书用户协议对未经腾讯授权的第三方接入、插件、工具和传播有明确限制，其中部分限制不以是否商业使用为条件。
5. 当前仓库仍是 source-only 里程碑。公开二进制、预装设备或应用商店发行必须先解决服务条款、上游许可、隐私、内容和商标问题。

## MIT 允许什么

在遵守 MIT 许可证通知要求的前提下，可以对项目自有代码进行个人、研究、教育、公益或商业使用，也可以修改、分发和销售副本。MIT 不要求修改版继续采用同一许可证，但分发时必须保留原版权和许可声明。

MIT 按“原样”提供软件，不提供适销性、特定用途适用性或不侵权保证，也不承诺设备兼容、服务可用、技术支持、商标许可或第三方权利清理。

## 微信读书相关风险

[微信读书用户协议](https://cdn.weread.qq.com/app/weread_user_agreement_android_s.html)第 6.1.2 节包含对以下行为的限制：

- 未经授权的第三方软件、插件、外挂或系统登录、使用服务。
- 获取或改变客户端与服务器的交互数据。
- 制作、运营或向公众传播相关工具，即使不以商业为目的。
- 使用、复制、链接、转载、汇编或发布腾讯拥有知识产权的内容。

项目 README 中的“非官方”、MIT 许可证和免责声明不能替代腾讯的书面许可，也不能对抗书籍作者、出版社、评论作者或其他权利人的权利。不得把用户缓存、书籍、封面、评论、凭据或账号数据放入安装包、演示数据、训练数据或公开日志。

## 产品化前的额外工作

MIT 本身不阻止商业使用项目自有代码，但使用微信读书服务或品牌的产品仍至少需要：

1. 与腾讯确认目标产品、账号体系、接口、数据范围、内容呈现、缓存方式和商业模式是否获得允许。
2. 获得微信读书名称、图标和其他商标或品牌元素的授权，或使用完全独立且不造成混淆的品牌。
3. 获得所有无明确许可上游的书面授权，或进行干净室替换并保存独立开发证据。
4. 为所有第三方依赖建立软件物料清单和许可证合规包。
5. 建立用户同意、隐私政策、数据最小化、加密、删除、账号隔离、日志脱敏和安全响应流程。
6. 由专业律师审查著作权、合同、个人信息保护、网络安全、消费者保护和设备改装责任。

如果无法取得所需的服务和内容授权，可行路径是停止使用微信读书接口和内容层，只保留经过权利审查的通用墨水屏 UI、排版和设备交互技术，并接入已正式授权的内容服务。
