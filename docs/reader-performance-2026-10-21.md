# 阅读优先优化验证（2026-10-21）

正常阅读停用手写笔迹层、工具栏和入口，不读取每页笔迹或清绘直接画布；旧数据保留。脚注与原有阅读设置仍可用。

翻页进度改为内存合并，停顿 800ms 后原子写盘，离开阅读、切书、休眠和正常退出强制保存；恢复位置包含尚未落盘的最新位置。连续翻页或触摸后至少 750ms 才允许单页补排。正文 HTML 每页一次提交，普通无脚注页面跳过笔迹定位行框。

## 设备对照

同一官方 SDK 构建、同一设备、同一套阅读设置，使用临时书库中每段独立编号的合成中文正文，先排好 24 页，再各翻 16 次。对照模式开启笔迹和同步进度保存，优化模式停用这些翻页开销；该对照不是对上一公开版本的精确测量，也不是官方微信读书或原生阅读器测试。

| 指标 | 对照模式 | 优化模式 |
| --- | ---: | ---: |
| 翻页主线程平均耗时 | 29.25ms | 12.12ms |
| Qt 首帧平均耗时 | 101.75ms | 79.25ms |
| Qt 首帧中位数 | 100ms | 77.5ms |
| Qt 首帧范围 | 82–140ms | 62–102ms |

首帧由 `QQuickWindow.frameSwapped` 计时，包含翻页处理到该 Qt 帧的间隔，**不代表物理墨水屏完全刷新时间**。这是单组小样本，不能据此保证所有书固定提升相同比例。早期重复文本试验放大了缓存收益，未作为上述结论；早期诊断构建最后退出异常，已将退出移出出帧回调，最终两组正常退出。

`RM_WEREAD_PERF_BASELINE=1` 只在 `reader-turn-perf` 临时书库模式允许启用对照，普通阅读即使该环境变量存在也不会启用笔迹。测试不联网、不提交真实进度或时长、不读取用户书籍和笔迹。
